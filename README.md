# دندان‌یار — نسخه توسعه‌یافته

وب‌اپلیکیشن فارسی و راست‌چین برای آموزش تعاملی بهداشت دهان و دندان به کودکان و دانش‌آموزان.

## بخش‌های نسخه دوم
- ترتیب آموزشی جدید: راز مسواک جادویی، راهنمای تصویری مرحله‌به‌مرحله مسواک‌زدن، مأموریت نخ دندان
- آموزش نخ دندان در سه بخش: معرفی، ویژگی‌های نخ مناسب، مراحل استفاده
- بخش آموزش تکمیلی درباره خوراکی‌ها و فلوراید
- بخش سؤال و جواب با پرسش‌های متداول و بازشونده
- مسابقه پنج‌پرسشی با بازخورد پاسخ‌ها، امتیاز و کاپ دیجیتال
- نوار پیشرفت، ذخیره امتیازها در همان مرورگر و طراحی واکنش‌گرا
- پشتیبانی پایه PWA و آفلاین پس از بارگذاری اولیه
- حفظ شخصیت و تصویرهای گرافیکی نسخه قبلی و استفاده از نمادهای تصویری موجود؛ تصویر تازه‌ای به پروژه اضافه نشده است

## اجرای سریع
فایل `index.html` را باز کنید. برای نصب‌پذیری PWA و Service Worker، سایت باید از طریق HTTPS یا localhost باز شود.

## انتشار در GitHub Pages
فایل‌های داخل این پوشه باید در ریشه مخزن GitHub باشند. برای انتشار، به Settings → Pages بروید و `main` و `/(root)` را انتخاب کنید. پس از ثبت تغییرات، GitHub Pages به‌طور خودکار سایت را دوباره منتشر می‌کند.

## یادداشت آموزشی
این برنامه محتوای آموزشی عمومی دارد و جایگزین توصیه شخصی دندان‌پزشک نیست. توصیه‌های مربوط به فلوراید و محصولات دهان باید پیش از استفاده رسمی توسط کارشناس سلامت یا دندان‌پزشک بازبینی شوند.

## محدودیت‌های فنی
- امتیازها فقط در همان مرورگر و دستگاه ذخیره می‌شوند؛ رتبه‌بندی مشترک بین مدارس به سرور و ورود امن نیاز دارد.
- تصویرهای مرحله‌ای این نسخه با نمادهای تصویری و طراحی‌های موجود ساخته شده‌اند؛ تصاویر واقعی/اختصاصی جدیدی اضافه نشده است.
